# Le La El La website

Home, support and privacy pages for the Le La El La iPhone app, plus the processed word lists it uses
(`data/`, shared under CC BY-SA 4.0 as the sources' licences require). Published with GitHub Pages:
https://mattjamespettitt.github.io/gender-trainer-site/

The word lists are copies of `public/fr-nouns.json` and `public/es-nouns.json` in the app's repo
(github.com/mattjamespettitt/gender-trainer). When the lists change, copy them here again as
`data/french-nouns.json` and `data/spanish-nouns.json` and update the counts on `data/index.html`.
